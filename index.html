使用说明

这份系统完全离线，数据只保存在当前浏览器。

快速开始

电脑打开

  1. 双击本 HTML 文件，用 Chrome、Edge 或其他现代浏览器打开。
  2. 点击“新建复盘”或“新增成语”开始录入，提交后自动保存。
  3. 以后继续打开同一个 HTML 文件，即可读取此浏览器中保存的数据。

手机离线使用

  1. 把本 HTML 文件发送到手机“文件管理”中，不要只放在聊天软件的临时预览里。
  2. 使用手机浏览器打开文件。安卓建议 Chrome、Edge；iPhone 可在“文件”中选择 Safari 打开。
  3. 可通过浏览器的“添加到主屏幕”或创建书签，方便下次进入。
浏览器本地数据与“浏览器 + 文件地址”绑定。更换浏览器、使用无痕模式或清除网站数据后，原记录可能无法读取。重要内容请定期导出完整 PDF。

PDF 导出

  • 单条复盘：在复盘卡片点击“PDF”。
  • 单模块：进入复盘库，选中顶部模块，再点击“导出当前模块”。
  • 完整合集：在学习概览点击“导出全部 PDF”，将包含目录、六大模块及成语库。
  • 手机导出后，文件通常进入“下载”或“文件”目录，可从系统分享菜单保存或转发。

功能分区

  • 学习概览：记录总量、模块分布、错误原因占比和最近复盘。
  • 复盘库：录入、筛选、查看、编辑、删除与导出六大模块复盘。
  • 成语库：独立管理成语释义、辨析和真题陷阱。
  • 全库检索：跨复盘与成语库搜索，并按模块、标签、错误原因筛选。
  • 草稿：未提交的表单内容会自动留存在当前浏览器，重新打开表单可继续填写。

智能易错分析

学习概览会在本机统计高频错误模块、二级板块、错误原因和近 30 天学习节奏，并自动给出复习建议。此功能不联网，不会上传错题或个人数据。

如需接入在线大模型进行更深入的逐题分析，需要网络和独立的安全接口。不要把个人 API 密钥直接写进可分享的 HTML 文件，否则密钥可能泄露。
